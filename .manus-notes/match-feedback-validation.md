# 圖片文字配對驗證紀錄

- 2026-08-27：手機版預覽可由首頁進入「遊戲天地」及「圖片文字配對」，16 張卡片與既有翻卡畫面正常載入。
- 2026-08-27：在圖片文字配對頁啟用右上角全域音樂開關後，控制項顯示「聲音：開啟，按此關閉」；音樂是否播放仍由使用者的全域開關偏好決定。
- 本輪不重新加入 Pop 或 Flip 音效；翻卡互動改由短暫發光與輕微震動動畫提供回饋。
- 2026-08-27：實際翻開「兔子」文字卡後，卡面正常完成 3D 翻轉，並顯示短暫金色發光回饋；未重新出現翻卡音效。
- 2026-08-27：遊戲天地的「圖片文字配對」主卡已於「立即開始」旁顯示獨立「🏆 排行榜」按鈕；兩個控制項均可在手機版獨立點按。
- 2026-08-27：未登入狀態可由新排行榜按鈕直接開啟公開排行榜，現有帳戶暱稱與最佳時間正常顯示，頁面同時清楚說明訪客只會以隨機匿名編號上榜。
