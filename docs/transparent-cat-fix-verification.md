# 遊戲天地探險小貓透明背景修正

## 問題與原因

先前的 `explorer-cat-transparent_97a48972.png` 將灰白棋盤格直接烙印在圖片像素中，因此在手機 Safari 顯示為可見背景，而不是真正的透明度。

## 修正

已從原始探險小貓圖建立 `explorer-cat-alpha_c47fe82f.png`，並確認該檔案為 2048 × 2048 的 RGBA PNG。遊戲天地現在統一使用此素材。

## 預覽驗證

在開發版實際進入「遊戲天地」後，小貓已直接顯示於米白漸層頁面上，沒有可見棋盤格；地圖闖關主卡與所有小遊戲入口仍可正常呈現。

## 單元測試

`client/src/components/WordGames.test.ts` 已驗證遊戲天地只引用新的 alpha PNG，避免再次連回舊棋盤格檔案。

## 正式版快取檢查

首次開啟正式網站時，瀏覽器仍可能保留舊版前端檔案並顯示舊圖片路徑；會以帶版本參數的網址重新載入，確認最新部署已套用新的透明素材。

帶版本參數重新載入後，正式網域仍回傳舊素材路徑，顯示發佈邊緣仍在使用前一版前端；開發版已正確套用新素材，會繼續以強制重載與版本狀態檢查排除快取問題。

正式網站完成邊緣更新後，已確認前端載入 `explorer-cat-alpha_c47fe82f.png`；實際遊戲天地畫面的小貓置於米白漸層背景上，沒有灰色棋盤格。
