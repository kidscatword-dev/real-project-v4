# 字詞報錯功能實作紀錄

更新日期：2026-08-25

## 回報資料範圍

「家長報錯」只提交結構化資料：權威詞語、正在使用的語言、問題類型、來源頁面、級別及地圖代碼。問題類型限於粵語讀音、普通話讀音、詞語顯示／粵普對照及其他問題。

系統**不提供自由文字欄位**，亦不保存姓名、電郵、使用者識別碼或裝置識別資料。回報可由詞卡直接送出，不要求孩子或家長登入。

## 詞卡入口

可重用的 `WordIssueReportButton` 已接入十級練習、自由查詞及溫習庫。面板會預先顯示目前的粵語／普通話主詞與括號對照詞；成功時顯示「已收到回報，多謝幫手！」。

## 驗證結果

已以手機直向版實測十級練習詞卡的報錯面板，確認四個選項可選取、私隱說明可讀、面板可正常關閉；亦已確認十級溫習庫詞卡顯示相同入口。未提交任何測試用回報，因此資料庫沒有因驗證產生非真實紀錄。

Vitest、TypeScript 檢查及正式建置均已通過。現有建置保留既有的非阻塞警告：字卡拼圖背景資源會於執行時解析，以及單一前端 chunk 超過建議大小。
