# 繁體認字樂：個人名義 App Store 準備

## 已確認的產品方案

| 項目 | 決定 |
| --- | --- |
| 發佈平台 | Apple App Store（iPhone 優先） |
| 開發者類型 | 個人名義 |
| 免費內容 | 初級：練習模式、地圖闖關、字卡收藏冊 |
| 付費內容 | 中級及高級：練習模式、地圖闖關、字卡收藏冊 |
| 商品類型 | 非消耗型一次性內購「家庭解鎖」 |
| 建議售價 | HK$48 |

> 個人名義加入 Apple Developer Program 時，App Store 會顯示帳戶持有人的法定個人姓名作為賣家／開發者名稱。[Apple Developer Program enrollment](https://developer.apple.com/programs/enroll/)

## 帳戶開通前置條件

使用 Apple Account 申請時，應先確認已啟用雙重認證，並準備法定姓名、聯絡電郵、電話、住址及可支付會籍費用的付款方式。Apple 官方列示 Developer Program 會籍為每年 US$99，實際收費會於報名時以本地貨幣顯示。[Apple Developer Program enrollment](https://developer.apple.com/programs/enroll/)

## 帳戶開通後的順序

1. 在 Apple Developer Program 以個人名義完成登記及驗證。
2. 登入 App Store Connect，建立「繁體認字樂」App 記錄及唯一 Bundle ID。
3. 簽署 Paid Apps 協議，填寫稅務與銀行收款資料。
4. 建立 HK$48 的非消耗型 In-App Purchase 商品「家庭解鎖」。
5. 以 TestFlight 測試初級免費、購買解鎖、回復購買及中級／高級權限。
6. 上載截圖、隱私政策、年齡分級、支援網址及 App Review 備註，再提交審核。

App Store Connect 可管理 App、In-App Purchase、TestFlight 測試、上架提交及收款協議資料。[App Store Connect](https://developer.apple.com/app-store-connect/)

## 尚待帳戶開通後確認

- 個人法定姓名將如何顯示於 App Store。
- Apple App ID 與 Bundle ID。
- App Store 支援電郵及隱私政策網址。
- 在 App Store Connect 選擇的最終商品識別碼，例如 `com.fantichinese.familyunlock`。
