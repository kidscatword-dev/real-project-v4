# 連續級別架構的參考依據

教育局的《香港小學學習字詞表》支援按「學習階段」排列字詞，並提供漢語拼音與多套粵語拼音的查找方式；其網頁亦說明詞表是參考性質而非唯一硬性標準。教育局的中國語文課程文件頁同時列出《中國語文課程指引（小一至小六）》及《小學中國語文建議學習重點》。

本網站的「第 1 級、第 2 級……」將作為**兒童認字遊戲的內部難度階梯**，不聲稱等同教育局年級或取代學校課程。級別安排會優先考慮具體生活經驗、字詞長度、字形複雜度、概念抽象程度及句法／文化知識負荷，並保留日後向上擴充的空間。

參考：

1. [香港小學學習字詞表](https://www.edbchinese.hk/lexlist_ch/)
2. [教育局：中國語文教育課程文件](https://www.edb.gov.hk/tc/curriculum-development/kla/chi-edu/curriculum-documents.html)
