# 遊戲更新設計紀錄

## 闖關小測驗

闖關小測驗保留在「遊戲天地」第三張主卡，改為只從溫習庫抽取最多五個詞，玩法統一為「聽字揀字」。答對後字詞仍留在溫習庫，方便反覆練習；選項會以同字數詞語隨機排列。

## 圖片文字配對排行榜

排行榜放在圖片文字配對遊戲內：遊戲進行頁上方有「查看時間排行榜」，完成一局後結果頁再顯示「查看全體時間排行榜」。這樣不會讓孩子在開始翻卡前分心，而完成後可以立即看見自己的成績。

跨網頁與 App 排名以家長登入帳戶連接同一家庭檔案。只顯示家長自行設定的暱稱與頭像，並只保存每個帳戶的最快有效完成時間及步數；不公開 OAuth 名稱、電郵、逐局紀錄或孩子個人資料。

## 全站控制

已從右上角控制列移除累積星星記錄；右上角保留既有的背景音樂開關。

開發站手機檢視確認：圖片文字配對頁面的排行榜入口位於倒數及配對進度下方、玩法指引前；不影響 4 欄 16 張翻卡版面。未登入時，入口會顯示家長登入說明，不會先行顯示任何玩家資料。

為驗證闖關小測驗，開發瀏覽器已建立「蘋果、香蕉、橙、西瓜、葡萄」五個暫時溫習庫詞語；此資料只存在開發瀏覽器本機，不會寫入正式資料庫或其他玩家帳戶。

實際進入闖關小測驗後，畫面顯示「第 1/5 題、答對 0 題」及「聽字揀字」，並提供粵語與普通話重聽按鈕；選項皆與題目同字數。測試環境所見的其他同字數選項只作干擾詞，題目仍只從暫時溫習庫的五個詞中抽取。

小測驗答題時，開發服務因剛儲存的程式修改觸發熱更新並重載回首頁，使原有按鈕索引失效；這是開發預覽狀態重置，非答題流程的使用者錯誤。正式建置後會以完整重載及單元測試再驗證。
