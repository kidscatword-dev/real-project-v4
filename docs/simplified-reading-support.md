# 簡體字閱讀支援研究筆記

## 技術轉換候選方案

2026-08-27 查閱 [OpenCC 官方專案](https://github.com/byvoid/opencc)。OpenCC 說明其支援繁體、簡體、日文新字體，以及中國大陸、臺灣與香港用詞之間的高品質轉換，並提供詞典及可重用的程式庫。

因此，網站可採用瀏覽器端繁轉簡字典，將現有十級詞庫中的顯示字詞轉為簡體，毋須複製或人工維護第二份完整詞庫。固定粵語／普通話音檔仍以既有詞條鍵值取用，不能用轉換後文字作為音檔查找鍵。

## 產品限制與建議

此功能應命名為「漢字顯示：繁體字／簡體字」，而非把整個香港繁體介面、遊戲規則或粵語詞形強制改成普通話。初版只轉換**字詞、題目選項及代表詞**；遊戲介面可保留香港繁體中文。長期如要面向普通話家庭，才另行提供「普通話學習」的詞形與介面文案。

簡體字模式必須讓同一局的答案與干擾詞一致轉換，並仍用原始繁體詞條作配對、進度、排行與音檔資料鍵。附文字的既有主題字卡圖片不能可靠自動改成簡體，因此初版應保留其原圖，並在字卡資料面／代表詞處提供簡體文字。

2026-08-27 查閱 [opencc-js 文件](https://github.com/nk2028/opencc-js)。這個純 JavaScript 實作同時支援瀏覽器與 Node.js，提供 `from: "hk", to: "cn"` 的香港繁體至大陸簡體轉換；字典會隨套件封裝，瀏覽器不需再下載字典或向外部服務傳送字詞。其文件同時指出結果大致對齊 OpenCC，但並不保證與官方輸出完全相同。因此實作後必須對十級詞庫進行轉換結果與同形選項衝突檢查。

現有程式已有粵語／普通話詞形工具，例如「雪糕／冰淇淋」及「巴士／公交車」。簡體顯示應在該工具輸出的可見文字上再轉換；語音繼續以使用者所選粵語或普通話及原始繁體詞條播放。若日後面向普通話家庭，可把簡體字模式的預設讀音設為普通話，但不應移除粵語選項。
