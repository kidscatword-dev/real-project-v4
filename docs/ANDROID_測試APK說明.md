# 繁體認字樂 Android 測試 APK

此測試 APK 以 Android WebView 載入目前的繁體認字樂網頁版，目的是讓家長在 Android 手機上測試全螢幕 App 式體驗、固定粵語／普通話讀音、地圖闖關、拼圖字卡與本機學習進度。

> 此版本需要網絡連線，因為 870 個固定語音檔及現有網頁內容仍由受管理的網頁服務提供。正式上架前，會改用穩定的公開網域，並評估把常用內容下載至裝置以支援離線使用。

## 安裝測試 APK

1. 把 APK 下載至 Android 手機。
2. 在檔案管理員點選 APK，按系統提示允許此來源安裝。
3. 安裝完成後，開啟「繁體認字樂」。
4. 首次及每次使用請保持網絡連線，然後測試首頁、練習模式、開始遊戲、字卡收藏冊及粵語／普通話讀音。

## 已知限制

這是開發簽署的測試 APK，並非 Google Play 正式版本。使用者可以手動安裝，但 Android 會顯示非商店來源的安全提示。手機更換、清除 App 資料或重新安裝後，本機學習進度會重設。由於它目前指向測試用網頁服務，該服務日後若有改動或停用，APK 會無法正常載入；因此不可把本版本視為長期或商店發佈版本。
