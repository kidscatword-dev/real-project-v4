# 地圖闖關單次自動讀音驗證

已由首頁進入遊戲天地，確認地圖闖關仍是唯一可進入的遊戲入口，並可進一步開啟三個級別地圖。程式修正以題目、級別、主題、關卡、語言組成穩定鍵值；同一題的重新渲染會略過自動播放，玩家仍可透過「再聽一次」按鈕主動重聽。

實際預覽已由遊戲天地進入初級地圖，並確認食物陸地可正常開啟；其他尚未解鎖陸地維持原有鎖定規則，未受本次讀音修正影響。

第一關開始頁維持原有「粵語／普通話」選擇及「播放讀音，開始作答」按鈕；第一題只會由此明確的開始操作自動播放一次，下一題則由穩定題目鍵控制單次自動播放。

實際開始第一題後，畫面只提供「再聽一次（2）」的玩家主動重聽控制。按下後次數正確降為「再聽一次（1）」，題目、計時與選項維持不變；此驗證了重聽不再由重新渲染自動觸發。
