# M35「團拜」詞語核對

初步選定的「團圓」實際已存在於第 9 級 M18「家族與關係」，而「團聚」亦同樣已在該地圖出現；為維持 1,260 詞全庫不重複，改以「團拜」取代 M35「傳統節日」的「互相」。

「團拜」是農曆新年中親友聚首互相拜年的傳統活動，適合置於香港「傳統節日」主題；其語義也能保留原詞「互相」的社交互動概念。
