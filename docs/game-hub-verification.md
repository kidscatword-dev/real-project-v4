# 遊戲樂園預覽驗證

- 已在本機預覽由首頁按「開始遊戲」進入「遊戲樂園」。
- 「地圖闖關」顯示為遊戲 1；「圖片文字配對」顯示為遊戲 2。
- 選單同時提供聽音揀字、拆字拼拼樂、闖關小測驗、找錯字及填字小空格入口。
- 遊戲樂園頁的音樂開關維持既有白色圓角樣式。

圖片文字配對頁的首張文字卡已實測可翻開並顯示「蘋果」；其餘圖畫卡在未翻開時維持統一卡背，符合配對玩法。

「蘋果」文字卡與圖畫卡已成功配對，畫面即時顯示「配對成功」、更新為 1/4 和回合 1，並保留綠色成功狀態及圖畫。

新版預覽已確認封面按鈕為「遊戲天地」。遊戲天地頁以小貓招手區、地圖闖關主卡、四色小遊戲方格及兩個迷你挑戰呈現；地圖闖關仍維持第一項，所有既有遊戲入口均可見。

探險小貓已取代遊戲天地原有小貓；標題下方與提示框已改為「一起來玩遊戲吧！」及「請選擇你想挑戰的遊戲。」。預覽確認地圖闖關、四張小遊戲卡及兩個迷你挑戰入口仍可見。

探險小貓現以透明背景素材顯示，並已放大；地圖闖關主卡的地圖插圖亦已放大。預覽確認二者均清晰可見，地圖闖關及其他遊戲入口仍保持可點擊。

本次調整後，冒險小貓由 144px 再放大至 176px，說話框仍清楚可讀且沒有重疊；地圖圖案移除原有白色圓角底框，保留圖案本身的道路與陸地細節並直接呈現在主卡漸層底上。「遊戲天地」標題改用較圓潤的無襯線字型，加上小星光點綴；地圖闖關、四色小遊戲格及兩個迷你挑戰入口皆維持可見。

依家長最新指示，遊戲天地現只開放「地圖闖關」。圖片文字配對、聽音揀字、拆字拼拼樂、闖關小測驗、找錯字及填字小空格均顯示鎖頭與「即將推出」，並設為不可點擊；地圖闖關主卡仍保留「立即開始」入口。
