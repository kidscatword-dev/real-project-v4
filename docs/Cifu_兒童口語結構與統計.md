# Cifu 兒童口語分類：資料結構與統計

> **摘要。** Cifu 的「兒童相關」資料不是一份已標註難度或主題的兒童教材詞表，而是同一詞條在兩個語域中的使用頻率：**兒童說話**（`SpokenChildren`）和**成人對兒童說話**（原檔欄名 `AdultToChild`）。在 51,798 個不重複詞條中，僅 3,695 個曾於至少一個兒童相關語域出現；因此 Cifu 適合做「粵語使用頻率的候選篩選器」，不適合不經審核直接變成兒童認字教材。[1] [2]

## 1. 資料來源與分析範圍

本報告直接分析 GitHub 倉庫中的 `Lexicon/Cifu-v1.txt`。原始檔以 Tab 分隔，含 51,798 筆資料列；以漢字詞條去重後仍為 51,798，表示每個詞條在此版本只有一列。論文亦將最終清單定為 51,798 個不同詞條，兩者一致。[1] [2]

本報告的「出現」是指某語域的原始出現次數（occurrences）大於 0；「每百萬詞」則是作者已預先依該語域語料庫規模正規化的頻率。這兩個數字不能互相替代：前者反映原始計數，後者才適合跨語域比較。[1]

| 項目 | 本次分析設定 |
|---|---|
| 詞表版本 | `Cifu-v1.txt` |
| 分析單位 | 漢字詞條（word entry） |
| 兒童說話欄 | `SpokenChildren`、`SpokenChildren (per million tokens)` |
| 成人對兒童說話欄 | `AdultToChild`、`AdultToChild (per million tokens)` |
| 統計方式 | 以原始詞表重算非零詞條、出現次數、詞長與高頻詞 |
| 不作的推論 | 不把高頻等同適合教材、不把語域欄當成年齡／年級標籤 |

## 2. 原始檔的 19 個欄位

原檔沒有 JSON 主題、年級、詞性或兒童適讀性標記。它的核心是四個語域的頻率欄，外加文字與心理語言學特徵。[1]

| 欄位群組 | 原始欄位 | 用途 |
|---|---|---|
| 詞條識別 | `Word`、`JyutPing` | 漢字詞條與粵拼；同一詞條可有多個讀音，以 `|` 分隔。 |
| 成人對兒童 | `AdultToChild`、每百萬詞頻率 | 成人向兒童說話的出現次數及正規化頻率。 |
| 成人口語 | `SpokenAdult`、每百萬詞頻率 | 成人口語的出現次數及正規化頻率。 |
| 書面語 | `Written`、每百萬詞頻率 | 書面語的出現次數及正規化頻率。 |
| 兒童說話 | `SpokenChildren`、每百萬詞頻率 | 兒童自身說話的出現次數及正規化頻率。 |
| 字形與釋義 | `NStrokes`、`Structure`、`Definition` | 筆畫數、IDS 字形結構與英文釋義。 |
| 音系鄰近密度 | 6 個 `ND` 欄 | 依是否容許插入／刪除，以及以書面、成人口語或平均頻率計算的鄰近密度；並**非**兒童專屬指標。 |

論文把兒童口語與成人對兒童口語的來源列為 HKU-70 與 Lee/Wong/Leung Corpus；作者為讓不同來源可比較，將全部語料重新分詞，再按語域計算頻率。[2]

## 4. 從 Cifu 原始詞表重算的兒童語域統計

### 4.1 詞條覆蓋

| 類別 | 詞條數 | 佔全表 51,798 詞條 |
|---|---:|---:|
| 兒童說話出現 | 2,489 | 4.80% |
| 成人對兒童說話出現 | 3,531 | 6.82% |
| 兩個兒童相關語域都出現 | 2,325 | 4.49% |
| 僅兒童說話出現 | 164 | 0.32% |
| 僅成人對兒童說話出現 | 1,206 | 2.33% |
| 至少一個兒童相關語域出現 | 3,695 | 7.13% |

兒童說話詞條中有 **93.41%** 同時也出現在成人對兒童說話語域；反過來，成人對兒童說話詞條中有 **65.84%** 同時出現在兒童說話語域。這表示兩者高度重疊，但成人對兒童說話還包含較多兒童未必自己產出的詞。

### 4.2 原始出現次數的分布

| 指標 | 兒童說話 | 成人對兒童說話 |
|---|---:|---:|
| 有出現詞條數 | 2,489 | 3,531 |
| 詞表內出現次數合計 | 173,698 | 586,834 |
| 詞表內合計相對論文語料 tokens | 99.97% | 83.14% |
| 非零詞條的中位數 | 5 | 5 |
| 非零詞條平均數 | 69.79 | 166.19 |
| 第 90 百分位 | 101 | 169 |
| 第 99 百分位 | 1,117 | 3,185 |

兩個語域的中位數都只有 5，但平均數遠高於中位數，說明頻率分布明顯右偏：少數功能詞、代詞及常用口語詞佔據大量出現次數。成人對兒童欄的 586,834 並不是論文所列 705,791 tokens；前者是經 Cifu 詞表保留規則後可歸到詞條的出現總和，後者是原始語料庫規模，兩者不可直接混用。[2]

### 4.3 漢字詞條長度

| 詞條字數 | 兒童說話 | 成人對兒童說話 |
|---|---:|---:|
| 1 字 | 1,039（41.74%） | 1,230（34.83%） |
| 2 字 | 1,250（50.22%） | 2,005（56.78%） |
| 3 字 | 188（7.55%） | 276（7.81%） |
| 4 字或以上 | 12（0.48%） | 20（0.56%） |

兩個兒童相關語域都以一至兩字詞為主，合計分別為 91.96% 與 91.61%。這對初級認字候選搜尋有幫助，但仍不能替代主題、具象性與書面語審核。

## 5. 如何理解「兒童口語」分類

> `SpokenChildren` 代表兒童自身在語料中說出的詞；`AdultToChild` 代表成人面向兒童的說話。兩者是**語料語域**，不是「小朋友已掌握」或「適合教學」的標籤。

論文報告兩者的全資料詞頻相關為 **r = .890**；作者指出成人對兒童說話包含大量確認問句、重複及修正，因此 token 多而詞類型相對少。[2] 這也解釋了為何高頻列表以「呢、唔、係、我、個、架、啦」等語法或口語互動詞為主，而不是水果、動物等適合製作圖卡的具象名詞。

## 6. 對《繁體認字樂》的採用建議

| 可做 | 不宜直接做 |
|---|---|
| 以 `SpokenChildren > 0` 或 `AdultToChild > 0` 作為粵語生活詞的**候選篩選條件**。 | 把全部 3,695 個兒童相關詞直接匯入學習網站。 |
| 在候選中優先檢視雙字具象名詞、日常動作與可畫圖的詞。 | 把頻率高低直接解讀為認字難度、教材優先序或年齡適合度。 |
| 使用 Cifu 的粵拼、詞頻和字形特徵作人工審核輔助。 | 以 `AdultToChild` 誤當「兒童說出的詞」。 |
| 對入選詞另做書面語、香港用字、詞義與家長／教師審核。 | 忽略 GPL-3.0 授權而直接複製、打包或再分發完整詞表。 |

若日後要擴充本網站的 870 詞，較穩妥的程序是：先用 Cifu 兒童相關欄作候選排序，再以香港書面語與主題教學需要人工篩選；最後才為確認的詞建立固定粵語／普通話讀音、圖片與地圖關卡。由於 Cifu 使用 GPL-3.0，若要在商業 App 中分發或實質整合其原始詞表，應先進行授權相容性審核。
