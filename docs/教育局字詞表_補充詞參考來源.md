# 教育局字詞表：補充詞規劃參考來源

本專案在規劃 26 個補充常用詞及十級地圖時，使用香港教育局的「香港小學學習字詞表」作為小學書面語與詞彙學習需要的**參考**，並非直接複製或把它當作逐詞考核清單。

教育局的資源頁列出「香港小學學習字詞表」及「中英對照香港學校中文學習基礎字詞」等小學中國語文參考材料。字詞表前言指出，字詞學習應放在語境中，並按學生學習需要選用；因此本網站仍以兒童日常情境、詞義清晰度、難度遞進及家長確認作最終篩選原則。

## 來源

1. 香港教育局，中國語文教育組：[香港小學學習字詞表](https://www.edbchinese.hk/lexlist_ch/)。
2. 香港教育局：[小學中國語文課程學與教資源](https://www.edb.gov.hk/tc/curriculum-development/kla/chi-edu/resources/primary/lang/curriculum-materials.html)。
3. 香港教育局：[Foreword to Hong Kong Chinese Lexical Lists for Primary Learning](https://www.edbchinese.hk/lexlist_en/fw_foreword_e.html)。
